Anibus Wiki

Полное руководство пользователя по сканеру безопасности Anibus Desktop 2.2.0. Wiki описывает рабочие процессы, окна интерфейса и каждый встроенный модуль — от пассивной разведки до анализа SourceMap и AI-сводки.

С чего начать Если вы впервые открыли Anibus — пройдите «Установка и запуск», затем «Базовые сканы». После этого изучайте модули по мере необходимости: каждая страница самодостаточна.

Что такое Anibus

Anibus — десктопный сканер на Java 21 (JavaFX 21.0.5, JPMS-модуль it.r2u.anibus) для пентеста, аудита периметра и непрерывного контроля безопасности. Все блокирующие IO-операции выполняются на virtual threads (JEP 444), сетевые запросы проходят через единый фасад HttpClientFactory с TLS, ретраями и таймаут-профилями.

Особенности

  • Локальный запуск без облака — все данные остаются на машине.
  • Поддержка EN / IT / RU локалей и тёмная/светлая темы.
  • Visual Proxy Chain Builder с drag-and-drop, ACTIVE CHAIN индикатор, ротация и chain-режим.
  • Виртуальные потоки для массовых HTTP-проб и параллельных детекторов.
  • Офлайн-кэш CVE/EPSS/KEV с обновлением по расписанию.

Карта функциональности

Базовые сканы

TCP/UDP, IPv6, service detection, баннеры, single-port mode, batch.

Web-уязвимости

XSS (DOM + Stored + polyglot), SSRF, XXE (OOB), CORS, JWT, GraphQL, SQLi (boolean+time+OOB).

Auth Crawling

5 режимов: Basic / Bearer / OAuth2 client_credentials / Digest RFC 7616 / Form + NTLMv2.

Passive Recon

Title, headers, robots, sitemap, favicon MD5, CSP-origin, meta-generator, email-OSINT, cross-origin policy.

Tech Stack 2.0

40+ сигнатур: серверы, CMS, JS-фреймворки, CDN, аналитика, cookie-runtimes.

CVE Intelligence

Офлайн NVD-кэш, EPSS-вероятность эксплуатации, флаг CISA KEV, exploit-maturity.

Network & Infra

ASN/BGP, GeoIP map, AXFR, HTTP/2/3 ALPN, IPv6, Traceroute TCP/UDP/ICMP, RDAP-fallback.

Container & TLS

Docker/K8s/etcd exposure, Weak TLS Policy, Auth Surface Audit, Heartbleed с false-positive guard.

Прокси-подсистема

Visual Chain Builder, ротация, ACTIVE CHAIN карта, multi-protocol chain.

Drift Scheduler

Расписания, baseline-профили, severity, suppression rules, алерты на новые порты.

Отчёты

PDF (PrinterJob), стилизованный HTML с JS-фильтром, история ~/.anibus/history/, diff-режим.

AI Summary

Эвристическая EN/RU executive-сводка по JS Analysis без внешних LLM.

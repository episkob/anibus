Базовые сканы

Стандартный TCP/UDP-скан, service detection, batch-режим и IPv6 — фундамент любого pentest-сеанса в Anibus.

Поле Target

Поле принимает:

  • IPv4: 192.168.1.10, диапазон 192.168.1.0/24.
  • IPv6: fe80::1 или [::1] (скобки strip автоматически).
  • Hostname: example.com (резолвится через HostResolver, поддержка нескольких A/AAAA).
  • URL: https://example.com/app/ — для web-сканов используется как baseUrl.

Диапазоны портов

В поле Ports принимаются:

  • Один порт: 443 (single-port mode добавлен в 2.2.0).
  • Диапазон: 1-1024.
  • Список: 22,80,443,8080-8090.
  • Пресеты: «Top 100», «Web», «DB», «Mail» — выбираются в выпадающем списке.

Standard Scan

Кнопка Scan запускает стандартный TCP-скан через StandardScanStrategy + ScanCoordinator. На каждый порт выделяется virtual thread, что позволяет работать с диапазонами в тысячи портов без блокировки UI.

[12:34:01] [INFO]  Scan started: 192.168.1.10 (1-1024)
[12:34:02] [OPEN]  22/tcp   SSH       OpenSSH 9.6p1
[12:34:02] [OPEN]  80/tcp   HTTP      nginx/1.25.3
[12:34:03] [OPEN]  443/tcp  HTTPS     nginx/1.25.3
[12:34:05] [INFO]  Scan finished in 4.2s · 3 open / 1021 closed

Service Detection

На каждом найденном порту запускается ServiceDetectionTask: HTTP HEAD, TLS handshake, баннер raw-сокета. Результаты пишутся в OPEN-строки и формируют входные данные для CVE/Vulnerability/JS-сканеров.

UDP Scan

Кнопка udpScanButton запускает UdpScannerService: отправка протокольно-зависимых пробов (DNS query, SNMP get-request, NTP request, NetBIOS name query). Ответ или ICMP-unreachable определяет состояние порта.

ICMP-quota Большинство ОС троттлит ICMP-unreachable — крупные UDP-сканы выполняются медленнее TCP. Используйте короткие списки портов (DNS/SNMP/NTP/NetBIOS).

IPv6 Scan

HostResolver в 2.2.0 поддерживает IPv6: распаковка [fe80::1], fallback IDN. Если хост имеет и A и AAAA, можно выбрать предпочитаемое семейство в Config → Network.

Batch / Multi-target

Меню Discovery → Batch Scan открывает BatchScanService: на вход — текстовый файл или вставка списка целей. Скан выполняется последовательно с агрегированным отчётом и общим заголовком в Scan Results.

192.168.1.0/24
example.com
fe80::1%eth0
https://app.internal/

Diff Mode

Кнопка diffModeButton запускает ScanDiffService: сравнение двух сохранённых сканов из ~/.anibus/history/. Отображаются:

  • NEW — новые открытые порты/находки.
  • CHANGED — изменения баннера/версии.
  • GONE — исчезнувшие сервисы.

Контекстное меню Scan Results

ПКМ по строке результата:

  • Сохранить в историю — текущий результат добавляется в ScanHistoryService.
  • Сравнить с… — открывает diff-мастер.
  • SQL Metadata Extraction — запускает SqlMetadataExtractor для SQLi-find.
  • Copy as curl — копирует curl-сниппет (из EndpointInfo).
  • Открыть PoC URL — для XSS/SSRF результатов с pocCurl().

Поиск по консоли

Ctrl+F открывает inline-фильтр Scan Results. Поиск realtime, регистр игнорируется. Дополнительные клавиши см. в Hotkeys.

Authenticated Crawling & Recon

Аутентифицированный обход, пассивная разведка и валидация секретов — для скрытного аудита без активной нагрузки.

Auth Crawler

Модуль AuthCrawler + UI-диалог Discovery → Auth Crawl. Поддерживает пять режимов аутентификации без внешних библиотек.

Режимы

РежимЧто делаетПоля диалога
BasicHTTP Basic Authorization: Basic base64(user:pass)Username, Password
BearerГотовый JWT/OAuth токен в Authorization: Bearer …Token
OAuth2 client_credentialsПолный grant flow с автообновлением токенаToken URL, client_id, client_secret, scope
Digest RFC 7616WWW-Authenticate challenge, MD5/SHA-256, qop=authUsername, Password (cnonce/nc — авто)
Form loginPOST формы + автоизвлечение CSRFLogin URL, поля username/password, имя CSRF-поля (опц.)

NTLMv2 NEW

Встроенный NtlmMessages реализует NTLMv2 Type-1 / Type-3 на собственных MD4 + HMAC-MD5 — никаких внешних JCE-провайдеров. Включается через диалог «NTLM credentials» в Auth Crawl.

CSRF auto-extract NEW

CsrfTokenExtractor читает токен из:

  • <meta name="csrf-token"> (Rails, Laravel, Spring).
  • <input type="hidden"> с типовыми именами: _token, __RequestVerificationToken, authenticity_token, csrfmiddlewaretoken.

Значение маскируется в отчёте (видно префикс/суффикс, ядро — звёздочки).

Cookie Flags Auditor

CookieFlagsAuditor парсит Set-Cookie и проверяет:

  • Secure на HTTPS.
  • HttpOnly для session/auth/jwt/token-куки → severity повышен.
  • SameSite (Strict/Lax/None+Secure).

Интегрирован в PassiveReconService.

Passive Recon Mode

Сервис PassiveReconService собирает данные без активных payload-ов — пригодно для разведки без алертов WAF/IDS.

Что собирается

  • HTML <title>, security-заголовки, robots.txt, sitemap.xml.
  • Favicon MD5 + сверка с FaviconFingerprintDatabase (Jenkins, GitLab, Confluence, JIRA, Grafana и др.).
  • NEW Все внешние origin из CSP-заголовка (connect-src, script-src, img-src).
  • NEW <meta name="generator"> — детект CMS/framework и версии.
  • NEW Email-адреса из HTML (с фильтром ложных по расширениям файлов).
  • NEW Cross-Origin headers (TAO, CORP, COOP, COEP, ACAO + wildcard/credentials/null-origin).

Secrets Validation

Проверка утечек ключей без отправки наружу. SecretsValidator валидирует формат:

  • AWS (AKIA…, ASIA…), GitHub PAT (ghp_*, github_pat_*), Stripe, Telegram, Slack (xox*), Google API.
  • NEW NPM token (npm_*), Docker Hub PAT (dckr_pat_*).
  • NEW Private key блоки PEM (BEGIN PRIVATE KEY, BEGIN RSA PRIVATE KEY).
  • NEW GCP Service Account JSON, Google OAuth Client Secret (GOCSPX-).
  • NEW Fuzzy-словарь (secret/password/token/apikey/access_key/auth/bearer) с фильтром placeholder-значений (scanFuzzy()).

Confidence & Risk Score

Каждое LeakInfo расширено:

  • confidence — HIGH / MEDIUM / LOW.
  • priority 1..3 — inferPriority().
  • placeholder — isPlaceholderValue() отсекает XXXXXX, your-key-here и т.п.
  • risk score = Severity × Exploitability × Exposure.

curl-сниппеты

EndpointInfo.toCurl() формирует готовую команду:

curl -X POST 'https://api.example.com/v1/users' \
  -H 'Authorization: Bearer eyJhbG...' \
  -H 'Content-Type: application/json' \
  --data-raw '{"role":"admin"}'

Доступно через ПКМ → Copy as curl на любом endpoint в JS Analysis.

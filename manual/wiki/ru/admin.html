Темы

Меню Config → Тема:

  • Тёмная (по умолчанию) — Bootstrap 5 Dark с кастомным CSS.
  • Светлая — override anibus-style-light.css, переключение через RadioMenuItem.

Словари

Файлы под ~/.anibus/wordlists/:

  • subdomains.txt — для SubdomainEnumerationService.
  • sqli-payloads.txt — для SQL Injection Analyzer (если не используется встроенный CMS-профиль).
  • endpoints.txt — для ParamMiner / Directory Bruteforce.

Статус активных словарей отображается в Scan Target UI.

Конфигурация

Пользовательские настройки хранятся в ~/.anibus/config.properties:

theme=dark
locale=ru
default.timeout.profile=NORMAL
proxy.chain.policy=strict
scheduler.enabled=true
cve.cache.refresh.hours=24

Hardening checklist

  1. Запускайте Anibus в изолированном сетевом сегменте (тестовая VLAN).
  2. Используйте dedicated пользовательский аккаунт без sudo, кроме UDP-сканов.
  3. Включите прокси-цепочку для всех внешних сканов — никаких прямых запросов.
  4. Очищайте ~/.anibus/history/ по политике (CRITICAL логи содержат потенциальные секреты).
  5. Регулярно обновляйте CVE Offline DB через Scheduler.
  6. Никогда не запускайте Anibus с доверенными корневыми сертификатами в системном TrustStore — используется InsecureSsl только внутри детекторов.

Troubleshooting

Не запускается JavaFX

Проверьте JDK 21 и наличие javafx-controls/fxml/graphics/base в classpath:

./mvnw -B -Pjavafx javafx:run

На Wayland при пустом окне попробуйте GDK_BACKEND=x11 ./mvnw ….

HTTP-таймауты на медленных целях

Config → Network → Default Timeout Profile → SLOW или VERY_SLOW.

NTLM-аутентификация не проходит

  • Убедитесь что домен указан в формате DOMAIN\\user, а не UPN.
  • Проверьте версию: NTLMv1 не поддерживается, только NTLMv2.
  • Логи: Discovery → Auth Crawl → Show Wire Trace.

Прокси-цепочка падает

  • В Build Chain → Test Chain: смотрите который узел отвалился.
  • Длинные SOCKS-цепочки требуют профиль SLOW.
  • Для TOR убедитесь что демон слушает на 9050.

CVE кэш пустой

  • Проверьте сетевой доступ к services.nvd.nist.gov (через chain если нужно).
  • Запустите ручное обновление: Scheduler → Update CVE DB now.
  • Для air-gapped — скопируйте ~/.anibus/cve-cache/ с подключённой машины.

Тесты падают

./mvnw -B test
./mvnw -B test -Dtest=SQLInjectionAnalyzerTest

Если фейлится ArchUnit — значит нарушены модульные границы (service→handler, util→handler, coordinator→JavaFX, model→coordinator).

Логи

Файл target/classes/logging.properties + рантайм-консоль с realtime timestamp. Уровни: INFO / WARN / ERROR / DEBUG. Уровень меняется через Config → Logging.

Graceful shutdown

shutdownExecutor() вызывает schedulerService.shutdown() и изолирует ошибки каждого сервиса через shutdownSafe(). Названные daemon-пулы (NamedThreadFactory.of()) — network-monitor, scan-scheduler — корректно завершаются при закрытии окна.

Юридические границы

Только авторизованное использование Anibus выполняет активные пробы (XSS, SSRF, SQLi, Heartbleed, NTLMv2 brute-вспомогательные операции). Эти действия в большинстве юрисдикций требуют письменного разрешения владельца ресурса.
  • Используйте только на собственной инфраструктуре или с подписанным rules-of-engagement.
  • Для public bug-bounty проверяйте scope конкретной программы.
  • Никогда не запускайте на цели без согласия — это уголовно наказуемо в РФ (УК 272/273), ЕС (Computer Misuse Act / Directive 2013/40) и США (CFAA).

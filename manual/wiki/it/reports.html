Esportazione e cronologia

Salvataggio, esportazione e analisi dei risultati: PDF, HTML, JSON, cronologia, diff e riepilogo AI.

Formati di esportazione

FormatoScopoComando
PDFReport stampabile per management / clienteExport → PDF (JavaFX PrinterJob)
HTMLReport interattivo con filtroExport → HTML
JSONMachine-readable, per integrazione SIEM/CIExport → JSON
TXTLog piatto della consoleExport → TXT oppure Ctrl+S

Report HTML

HTML stilizzato con tabella dei risultati e filtro JS integrato (ricerca per testo, filtro per severity, collapse delle sezioni). Non richiede un server — si apre direttamente nel browser.

PDF

PrinterJob di JavaFX renderizza il report DOM pagina per pagina. Intestazione con target, data, versione Anibus; tabella CVE; sezione JS Analysis; appendice con snippet PoC curl.

Cronologia scansioni

ScanHistoryService salva automaticamente ogni scansione conclusa in ~/.anibus/history/ con nome del tipo 2026-05-15T12-34-01_example.com.scan.json.

Visualizzazione

Menu Discovery → Scan History:

  • Lista delle scansioni con filtro per data/target.
  • Doppio clic — apre.
  • Tasto destro → Compare with… avvia il diff.
  • Tasto destro → Re-run ripete la scansione con gli stessi parametri.

Modalità Diff

ScanDiffService confronta due snapshot JSON della cronologia:

  • NEW — nuove porte aperte, nuove CVE, nuovi leak.
  • CHANGED — versione/banner cambiati.
  • GONE — porta chiusa o vulnerabilità sparita.

Il pulsante diffModeButton nella schermata principale apre un wizard con due menu a tendina di scansioni.

Statistic Dashboard

Scheda con grafici di distribuzione:

  • Porte aperte per top service.
  • Vulnerabilità per severity (CRITICAL/HIGH/MEDIUM/LOW).
  • Top ASN/paesi (tramite GeoIP).
  • Dinamica delle scansioni di drift da ScanHistoryService.

AI Summary NEW

AiSummaryGenerator produce un riepilogo executive per JS Analysis senza LLM esterni. Algoritmo euristico:

  • Severity buckets (Critical / High / Medium / Low / Informational).
  • Top-5 categorie di scoperte (Secrets / Endpoints / Configs / Schemas / Cookies / Generators / Other).
  • Top-3 scoperte per risk score (Severity × Exploitability × Exposure).
  • Raccomandazioni type-aware: per chiavi AWS — rotazione + audit di CloudTrail; per GitHub PAT — revoke e revisione della history dei commit, ecc.

Prodotto in due lingue contemporaneamente (EN / RU). Disponibile nella scheda JS Analysis → Summary.

SourceMap Exploit Context NEW

SourceMapExploitContextAnalyzer arricchisce ogni LeakInfo estratto dalla source map con un'annotazione:

  • category — classe di attacco (SSRF / Auth-bypass / Privilege-escalation / Data-exfil / RCE).
  • narrative — breve descrizione del contesto (da dove proviene la chiave, come è usata).
  • recommendation — azione concreta (rotazione / rimozione / vault).
  • ref — link a CVE / categoria OWASP.

Ordinamento e filtro

  • JS Analysis ordina le scoperte per priority (decrescente) all'interno di ciascun tier di severity.
  • Ctrl+F — filtro inline di Scan Results.
  • Il report HTML ha un filtro JS indipendente nel browser.

Notifiche di sistema

NotificationService tramite java.awt.SystemTray mostra notifiche di tray:

  • «Scan finished» — al termine.
  • «CRITICAL detected» — alla prima scoperta CRITICAL.
  • «Scheduler drift» — variazioni nella drift baseline.

Esportazione batch

Da BatchScanService il report viene esportato in un unico archivio: batch-YYYYMMDD.zip contiene JSON per-target + un HTML riassuntivo.

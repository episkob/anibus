Network & infrastructure

ASN/BGP enrichment, GeoIP map, AXFR, HTTP/2 and HTTP/3 ALPN, IPv6, traceroute in three modes, WHOIS with RDAP fallback.

ASN / BGP Enrichment NEW

BgpInfo record + Team Cymru whois bulk query:

  • ASN, owner, country, prefix, route age.
  • Neighbouring ASNs.
  • Bulk lookups over TCP whois (no HTTP API).

Used by the Topology Map (hop clustering by /24 + ASN) and by JS Analysis to classify CDN / cloud providers.

ASN Lookup (standalone)

AsnLookupService — resolves AS for an IP by parsing whois/IANA without any external API. Menu Discovery → ASN Lookup.

GeoIP Map View NEW

GeoIpService + ASCII bar chart by country. Output:

US ████████████████████  42
DE ███████              14
NL ████                  9
RU ██                    4
CN █                     2

Local GeoIP source (no runtime calls to MaxMind).

Network Topology Map

A dedicated tab visualizes traceroute as a hop→hop graph:

  • NEW Hop clustering by /24 prefix + ASN.
  • NEW Zoom-to-fit, manual mouse-wheel zoom, drag-pan.
  • Highlights failure points (high ICMP loss).

Traceroute (3 modes)

TracerouteService.Mode enum:

ModeWhen to use
ICMPThe classic Linux traceroute; may be filtered by firewalls.
UDPUDP packet on a high port; bypasses some ICMP filters.
TCPSYN on a specific port (80/443) — passes most NAT/SPI devices.

Metrics: hop, ASN, RTT min/avg/max, packet-loss %, owner.

WHOIS Lookup + RDAP

WhoisService:

  • Two-step query: IANA root → authoritative server.
  • NEW RDAP fallback for modern registries (.io, .dev, .app).
  • NEW Normalization of registrar / abuse contact fields across different formats.

DNS Zone Transfer (AXFR)

Raw TCP/53 AXFR with no third-party libraries. Records A / AAAA / NS / MX / CNAME are parsed and printed as a tree. If AXFR is forbidden, the failure is handled gracefully without console noise.

HTTP/2 + HTTP/3 detector

  • HTTP/2 — ALPN negotiation (h2) on 443/TLS.
  • HTTP/3 — Alt-Svc: h3=":443" header + UDP/443 probe.

WebSocket Detector

HTTP Upgrade: websocket probe against 17 typical paths (/ws, /socket.io/, /cable, /api/ws, …). On success, the protocol is recorded (Sec-WebSocket-Protocol).

IPv6

HostResolver supports IPv6:

  • Strips square brackets: [::1] → ::1.
  • Skips IDN handling for raw IPv6.
  • Multi-resolution: A + AAAA simultaneously.
  • Zone-ID for link-local: fe80::1%eth0.

SSL/TLS Deep Audit

SslTlsAuditor produces an AuditResult:

  • Protocol, cipher suite, certificate chain, SAN list, expiry.
  • NEW OCSP URL, HSTS header, ALPN list.
  • NEW Chain trust through the default JVM TrustManager.

The result feeds Weak TLS Policy Alerts.

Port Banner Timeline NEW

BannerTimelineService stores a TSV store under ~/.anibus/banner-timeline/. Each port keeps a history (timestamp + banner). A diff between two points shows service updates (for example, OpenSSH 9.0p1 → 9.6p1).

Reverse DNS Expander

ReverseDnsExpander — expands PTR records for a CIDR block over virtual threads. Useful for inventorying a corporate range.

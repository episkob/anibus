Anibus Wiki

Complete user guide for the Anibus Desktop 2.2.0 security scanner. This wiki documents workflows, UI screens and every built-in module — from passive recon to SourceMap exploitation and AI summary.

Where to start First time with Anibus? Read Install & run, then Basic scans. After that, explore modules as needed — each page is self-contained.

What is Anibus

Anibus is a desktop scanner built on Java 21 (JavaFX 21.0.5, JPMS module it.r2u.anibus) for penetration testing, perimeter audit and continuous security monitoring. All blocking IO runs on virtual threads (JEP 444), network requests go through a unified HttpClientFactory facade with TLS, retries and timeout profiles.

Highlights

  • Runs locally with no cloud — all data stays on your machine.
  • EN / IT / RU locales and dark/light themes.
  • Visual Proxy Chain Builder with drag-and-drop, ACTIVE CHAIN indicator, rotation and chain mode.
  • Virtual threads for mass HTTP probes and parallel detectors.
  • Offline CVE/EPSS/KEV cache with scheduled refresh.

Functionality map

Basic scans

TCP/UDP, IPv6, service detection, banners, single-port mode, batch.

Web vulnerabilities

XSS (DOM + Stored + polyglot), SSRF, XXE (OOB), CORS, JWT, GraphQL, SQLi (boolean+time+OOB).

Auth Crawling

5 modes: Basic / Bearer / OAuth2 client_credentials / Digest RFC 7616 / Form + NTLMv2.

Passive Recon

Title, headers, robots, sitemap, favicon MD5, CSP origin, meta-generator, email OSINT, cross-origin policy.

Tech Stack 2.0

40+ signatures: servers, CMS, JS frameworks, CDN, analytics, cookie runtimes.

CVE Intelligence

Offline NVD cache, EPSS exploitation probability, CISA KEV flag, exploit maturity.

Network & Infra

ASN/BGP, GeoIP map, AXFR, HTTP/2/3 ALPN, IPv6, Traceroute TCP/UDP/ICMP, RDAP fallback.

Container & TLS

Docker/K8s/etcd exposure, Weak TLS Policy, Auth Surface Audit, Heartbleed with false-positive guard.

Proxy subsystem

Visual Chain Builder, rotation, ACTIVE CHAIN card, multi-protocol chain.

Drift Scheduler

Schedules, baseline profiles, severity, suppression rules, alerts on new ports.

Reports

PDF (PrinterJob), styled HTML with JS filter, history under ~/.anibus/history/, diff mode.

AI Summary

Heuristic EN/RU executive summary on top of JS Analysis without external LLMs.

Administration and troubleshooting

Hotkeys, themes, wordlists, hardening checklist, common errors and the legal boundaries of using Anibus.

Hotkeys

KeyAction
F5Run a standard scan of the current Target
EscapeStop the active operation
Ctrl+SSave the Scan Results log to TXT
Ctrl+LClear the console
Ctrl+FInline console filter

Themes

Menu Config → Theme:

  • Dark (default) — Bootstrap 5 Dark with custom CSS.
  • Light — the anibus-style-light.css override, switched via a RadioMenuItem.

Wordlists

Files under ~/.anibus/wordlists/:

  • subdomains.txt — for SubdomainEnumerationService.
  • sqli-payloads.txt — for the SQL Injection Analyzer (when the built-in CMS profile is not used).
  • endpoints.txt — for ParamMiner / Directory Bruteforce.

The active wordlist status is shown in the Scan Target UI.

Configuration

User settings live in ~/.anibus/config.properties:

theme=dark
locale=ru
default.timeout.profile=NORMAL
proxy.chain.policy=strict
scheduler.enabled=true
cve.cache.refresh.hours=24

Hardening checklist

  1. Run Anibus in an isolated network segment (a test VLAN).
  2. Use a dedicated user account without sudo, except for UDP scans.
  3. Enable a proxy chain for every external scan — no direct requests.
  4. Purge ~/.anibus/history/ on a policy (CRITICAL logs may contain secrets).
  5. Keep the CVE Offline DB updated via the Scheduler.
  6. Never run Anibus with trusted root certificates injected into the system TrustStore — InsecureSsl is used only inside detectors.

Troubleshooting

JavaFX won't start

Check JDK 21 and that javafx-controls/fxml/graphics/base are on the classpath:

./mvnw -B -Pjavafx javafx:run

If the window is empty on Wayland, try GDK_BACKEND=x11 ./mvnw ….

HTTP timeouts against slow targets

Config → Network → Default Timeout Profile → SLOW or VERY_SLOW.

NTLM authentication fails

  • Make sure the domain is provided as DOMAIN\\user, not UPN.
  • Check the version: NTLMv1 is not supported, only NTLMv2.
  • Logs: Discovery → Auth Crawl → Show Wire Trace.

The proxy chain drops

  • In Build Chain → Test Chain: see which node failed.
  • Long SOCKS chains need the SLOW profile.
  • For TOR, make sure the daemon is listening on 9050.

CVE cache is empty

  • Check network access to services.nvd.nist.gov (via the chain if needed).
  • Trigger a manual refresh: Scheduler → Update CVE DB now.
  • For air-gapped setups — copy ~/.anibus/cve-cache/ from a connected machine.

Tests fail

./mvnw -B test
./mvnw -B test -Dtest=SQLInjectionAnalyzerTest

If ArchUnit fails, module boundaries are violated (service→handler, util→handler, coordinator→JavaFX, model→coordinator).

Logs

The file target/classes/logging.properties + the runtime console with realtime timestamps. Levels: INFO / WARN / ERROR / DEBUG. The level is changed via Config → Logging.

Graceful shutdown

shutdownExecutor() calls schedulerService.shutdown() and isolates per-service errors via shutdownSafe(). The named daemon pools (NamedThreadFactory.of()) — network-monitor, scan-scheduler — terminate cleanly when the window closes.

Legal boundaries

Authorized use only Anibus performs active probes (XSS, SSRF, SQLi, Heartbleed, NTLMv2 brute-force helpers). In most jurisdictions these actions require written authorization from the resource owner.
  • Use only on your own infrastructure or under a signed rules-of-engagement document.
  • For public bug bounty programs, verify the scope of the specific program.
  • Never run against a target without consent — it is a criminal offense in the EU (Computer Misuse Act / Directive 2013/40), the United States (CFAA) and Russia (Criminal Code articles 272/273).

Install & run

The minimal path from a clean system to your first scan in Anibus 2.2.0.

System requirements

ComponentMinimumNotes
OSLinux x64 / macOS / Windows 10+Tested on Linux (Fedora/Ubuntu). No quirks on Wayland.
JDKJava 21 (LTS)Requires virtual threads support (JEP 444); no preview flags needed.
JavaFX21.0.5Pulled in as a Maven dependency; separate install is not required.
Maven3.9+The project ships ./mvnw, which you can use directly.
RAM1 GBFor batch scans of 100+ targets, 2 GB or more is recommended.
PrivilegesRegular userSome UDP service scans may require root / CAP_NET_RAW.

Building from source

git clone <repo> anibus-desktop
cd anibus-desktop
./mvnw -B -DskipTests package
./mvnw -B -Pjavafx javafx:run

Build artifacts land in target/. The test suite (162 tests, 50+ classes) is run with:

./mvnw -B test

Running a single test:

./mvnw -B test -Dtest=SQLInjectionAnalyzerTest

First launch

  1. The window opens in the dark theme (Bootstrap 5 Dark with custom CSS).
  2. The window title shows the version Anibus Desktop 2.2.0.
  3. The left pane contains the Target field and the scan button group.
  4. The centre is the Scan Results console with realtime timestamps and a filter (Ctrl+F).
  5. The top menu gives access to configuration, theme, wordlists, proxy, scheduler, export.
Tip On first launch, open Config → Theme and pick Dark or Light. The light theme is an override CSS file anibus-style-light.css.

User directory layout

PathPurpose

~/.anibus/cve-cache/Offline CVE/EPSS/KEV cache (see CVE Offline DB).

~/.anibus/banner-timeline/TSV store for the Port Banner Timeline.

UI overview

Main window

  • Target — IPv4/IPv6/hostname/URL; square brackets in IPv6 are stripped automatically.
  • Scan Results — console grouped into CRITICAL/HIGH/MEDIUM/LOW. Context menu → history, diff, SQL extraction.
  • Buttons on the left — Scan, UDP, Subdomain, Source Map, ParamMiner, Diff Mode, Scheduler Start/Stop, etc. Details in Basic scans.
  • Status bar — indicators for active wordlists, proxy chain, scheduler state.

Menus

  • Config — theme, language, wordlists, timeout profiles.
  • Discovery — Auth Crawling, Passive Recon, GraphQL/JWT/CORS dialogs, batch import.
  • Proxy — Build Chain, ACTIVE CHAIN, rotation.
  • Scheduler — schedules, drift baseline.
  • Export — PDF, HTML, JSON, TXT.

Localization

All UI strings live in three bundles: Messages_en, Messages_it, Messages_ru. Key parity is enforced by the JUnit test ResourceBundleValidationTest. The locale is taken from the system and can be switched explicitly in Config → Language.

What's next

  • Run your first scan against any target you are explicitly allowed to scan (scanme.nmap.org or your own lab).
  • Study proxy chains if you scan through a corporate gateway.
  • Enable the offline CVE cache if you work in an air-gapped environment.

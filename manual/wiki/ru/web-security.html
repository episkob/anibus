Web-уязвимости

Все детекторы для web-сканирования: XSS, SSRF, XXE, CORS, JWT, GraphQL, SQL Injection, Directory Bruteforce, JS Analysis. В 2.2.0 каждый анализатор расширен новыми техниками.

XSS Detector

Класс XssDetector. Покрывает reflected, DOM-based и stored XSS.

Reflected (canary-based)

Для каждого query-параметра генерируется canary-строка вида anibus-xss-7f2a, инжектится и ищется в ответе вместе с типичными контекстами.

Context-aware экранирование NEW 2.2

Рефлексия классифицируется по контексту через enum XssDetector.Context:

  • SCRIPT_BLOCK / JS_STRING / URL_ATTRIBUTE — severity CRITICAL.
  • HTML_TEXT / HTML_ATTRIBUTE — severity HIGH.
  • STYLE_BLOCK / HTML_COMMENT — severity MEDIUM.

В XssResult добавлено поле с рекомендацией по экранированию для конкретного контекста.

DOM-based sink/source mapping NEW

XssDetector.analyzeDomSinks() сканирует inline-скрипты на пары source→sink: location.hash → innerHTML, document.referrer → eval и т.п. Результат отображается отдельной таблицей в JS Analysis.

Stored XSS NEW

XssDetector.scanStored(injectUrl, params, verifyUrl): инжектится canary через injectUrl, затем выполняется GET verifyUrl и проверяется рефлексия. Если найдена — XssResult.stored=true, риск эскалируется до CRITICAL.

Polyglot payload set NEW

10 техник: SVG/onload, iframe srcdoc, math/mglyph break-out, body onpageshow, details ontoggle, input autofocus, template literal ${...}, style break-out, jaVasCript: scheme polyglot.

PoC-генерация

Для каждого результата — XssResult.pocCurl() строит готовый curl-сниппет с payload и заголовками, доступен через ПКМ → Copy PoC.

SSRF Detector

  • URL-параметры на SSRF + проверка cloud metadata (AWS 169.254.169.254, GCP, Azure IMDS).
  • NEW Поддержка file://, dict://, gopher://, ftp:// схем.
  • NEW IPv6/IPv4-mapped bypass (::ffff:169.254.169.254), октальные/hex/decimal IP-форматы, short-form (127.1), nip.io DNS rebinding.

XXE Detector

  • 5 базовых payload-ов + детект по сигнатурам в ответе.
  • NEW OOB XXE через встроенный LoopbackCallbackServer на 127.0.0.1:random — внешний сервер не нужен.
  • NEW scanWithBaseline() — blind XXE/SSRF через diff длины ответа.
  • NEW Error-based payload (несуществующий путь / закрытый порт) с индикаторами Connection refused, failed to open stream, DOCTYPE is disallowed.

CORS Misconfiguration Checker

  • Проверка Access-Control-Allow-Origin + credentials комбинаций.
  • NEW Детект credentials + * (нарушение спеки).
  • NEW Per-endpoint sweep — check(baseUrl, endpoints).
  • NEW Null-origin probe (Origin: null) и pre-flight headers.

JWT Analyzer

  • Декодирование, alg:none, expired, weak HMAC секреты.
  • NEW JWK/JWKS проверка (analyzeJwks), kid injection, alg-confusion.
  • NEW Kid path traversal (kid: "../../etc/passwd") + SQLi в kid.
  • NEW Небезопасное хранение токена — поиск localStorage ключей в JS-бандлах.
  • NEW compareTokenPair(access, refresh) — TTL-diff advisories.
  • NEW cloneWithClaim(token, claim, value) — тампер sub/role для probing.

GraphQL Introspection

  • 10 путей, __schema, извлечение типов/queries/mutations.
  • NEW Batch query abuse — массив запросов за один HTTP-вызов.
  • NEW Авто-генерация минимальных query/mutation из схемы.
  • NEW Depth-limit probe (глубина 12) → флаг depthLimitMissing.

SQL Injection Analyzer

  • Загрузка payload-файлов + CMS-профилей.
  • NEW Boolean-based blind через длину ответа и статус-код diff.
  • NEW 8 explicit time-based payloads (SLEEP/WAITFOR/pg_sleep/BENCHMARK).
  • NEW OOB payload generator buildOobPayloads(callbackUrl) — MSSQL/Oracle/PostgreSQL/MySQL outbound primitives через LoopbackCallbackServer.
  • SQL-to-DB Extraction: контекстное меню → SqlMetadataExtractor (UNION-based version/columns/tables, ORDER BY probe).

Directory Bruteforce

  • 60-entry default wordlist, HEAD-запросы, группировка по статусу.
  • NEW Кастомные wordlist/расширения + recursion depth — scan(url, words, exts, depth, progress).
  • NEW IIS short-name enumeration (probeIisShortNames()).
  • NEW Detection backup-файлов (.bak, .old, .orig, ~, .swp).
  • NEW Авто-расширения по Content-Type/Server (PHP → .php/.phtml, IIS → .aspx, Tomcat → .jsp).
  • NEW Отображение HTTP-заголовков (Content-Type, X-Powered-By, Server).

Subdomain Enumeration & Takeover

  • 30+ субдоменов на dangling DNS, HTTP-fingerprint.
  • NEW CNAME chain рекурсия через JNDI DNS (resolveCnameChain).
  • NEW +24 fingerprints: Vercel, Render, Fly.io, Pantheon, Strikingly, Tumblr, Campaign Monitor, WordPress, Ngrok, Help Scout, Wishpond, Readme.io, AWS EB, Smartling, Acquia, LeadPages, Railway.
  • NEW DNS wildcard baseline — random субдомен; при совпадении выдаётся одно *.domain предупреждение вместо ложных срабатываний.

API Security Mode

  • Авто-детект OpenAPI/Swagger, тестирование всех endpoints.
  • NEW Поддержка GraphQL/gRPC/OpenRPC схем (unified report).
  • NEW Diff authenticated vs anonymous ответов.
  • NEW Rate-limit probe — серия из 20 запросов, ожидание 429.
  • NEW Авто-парсинг HAR / Postman v2.x через HarPostmanParser.
  • NEW Enum-fuzzing query-параметров (role/status/sort/order/filter/debug).
  • NEW BOLA/IDOR probe — runBolaProbe() сравнивает {id}=1 vs {id}=2.

JavaScript Security Analyzer

Универсальный анализатор JS-бандлов: разбор источников, поиск секретов, схем БД, endpoints. Каждая находка — LeakInfo с полями:

  • priority — 1..3, см. inferPriority().
  • confidence — HIGH / MEDIUM / LOW.
  • placeholder — флаг что значение похоже на демо-плейсхолдер.
  • risk score — Severity × Exploitability × Exposure.

JS Endpoint Reachability NEW

Найденные из JS endpoints проверяются на живость, статус и метод. Результат — таблица Reachable / 401 / 403 / 404 / 5xx с curl-сниппетом для каждого живого URL.

AI Summary NEW

AiSummaryGenerator формирует EN/RU executive-сводку: severity buckets, top-5 категорий, top-3 risk-scored находки, type-aware рекомендации. Полностью оффлайн, без LLM-API.

OOB-инфраструктура

LoopbackCallbackServer — встроенный HTTP-listener на 127.0.0.1:random. Используется в SSRF/XXE/SQLi/Blind XSS payload-ах для подтверждения out-of-band-факта без внешнего интернет-инфра.

Внимание Все детекторы web-уязвимостей выполняют активные запросы. Используйте только на разрешённых целях. Для пассивного аудита — Passive Recon.

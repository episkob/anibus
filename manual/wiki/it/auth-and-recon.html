Authenticated Crawling & Recon

Crawling autenticato, ricognizione passiva e validazione di segreti — per audit silenziosi senza carico attivo.

Auth Crawler

Modulo AuthCrawler + dialogo UI Discovery → Auth Crawl. Supporta cinque modalità di autenticazione senza librerie esterne.

Modalità

ModalitàCosa faCampi del dialogo
BasicHTTP Basic Authorization: Basic base64(user:pass)Username, Password
BearerToken JWT/OAuth già pronto in Authorization: Bearer …Token
OAuth2 client_credentialsFlusso grant completo con refresh automatico del tokenToken URL, client_id, client_secret, scope
Digest RFC 7616Challenge WWW-Authenticate, MD5/SHA-256, qop=authUsername, Password (cnonce/nc — automatici)
Form loginPOST del form + auto-estrazione del CSRFLogin URL, campi username/password, nome del campo CSRF (opz.)

NTLMv2 NEW

NtlmMessages integrato implementa NTLMv2 Type-1 / Type-3 con MD4 + HMAC-MD5 propri — nessun provider JCE esterno. Si attiva tramite il dialogo «NTLM credentials» in Auth Crawl.

Auto-estrazione CSRF NEW

CsrfTokenExtractor legge il token da:

  • <meta name="csrf-token"> (Rails, Laravel, Spring).
  • <input type="hidden"> con i nomi tipici: _token, __RequestVerificationToken, authenticity_token, csrfmiddlewaretoken.

Il valore viene mascherato nel report (si vedono prefisso/suffisso, il centro con asterischi).

Cookie Flags Auditor

CookieFlagsAuditor esegue il parsing di Set-Cookie e verifica:

  • Secure su HTTPS.
  • HttpOnly per cookie session/auth/jwt/token → severity aumentata.
  • SameSite (Strict/Lax/None+Secure).

Integrato in PassiveReconService.

Passive Recon Mode

Il servizio PassiveReconService raccoglie dati senza payload attivi — adatto a ricognizione senza allarmi WAF/IDS.

Cosa viene raccolto

  • <title> HTML, header di sicurezza, robots.txt, sitemap.xml.
  • Favicon MD5 + confronto con FaviconFingerprintDatabase (Jenkins, GitLab, Confluence, JIRA, Grafana, ecc.).
  • NEW Tutte le origin esterne dall'header CSP (connect-src, script-src, img-src).
  • NEW <meta name="generator"> — rilevamento di CMS/framework e versione.
  • NEW Indirizzi email dall'HTML (con filtro dei falsi positivi per estensione file).
  • NEW Header Cross-Origin (TAO, CORP, COOP, COEP, ACAO + wildcard/credentials/null-origin).

Secrets Validation

Verifica dei leak di chiavi senza invii esterni. SecretsValidator convalida il formato:

  • AWS (AKIA…, ASIA…), GitHub PAT (ghp_*, github_pat_*), Stripe, Telegram, Slack (xox*), Google API.
  • NEW Token NPM (npm_*), Docker Hub PAT (dckr_pat_*).
  • NEW Blocchi PEM di chiave privata (BEGIN PRIVATE KEY, BEGIN RSA PRIVATE KEY).
  • NEW GCP Service Account JSON, Google OAuth Client Secret (GOCSPX-).
  • NEW Dizionario fuzzy (secret/password/token/apikey/access_key/auth/bearer) con filtro per i valori placeholder (scanFuzzy()).

Confidence & Risk Score

Ogni LeakInfo è esteso con:

  • confidence — HIGH / MEDIUM / LOW.
  • priority 1..3 — inferPriority().
  • placeholder — isPlaceholderValue() esclude XXXXXX, your-key-here ecc.
  • risk score = Severity × Exploitability × Exposure.

Snippet curl

EndpointInfo.toCurl() compone un comando pronto:

curl -X POST 'https://api.example.com/v1/users' \
  -H 'Authorization: Bearer eyJhbG...' \
  -H 'Content-Type: application/json' \
  --data-raw '{"role":"admin"}'

Disponibile tramite tasto destro → Copy as curl su qualsiasi endpoint in JS Analysis.

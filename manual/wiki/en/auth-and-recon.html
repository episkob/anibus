Authenticated Crawling & Recon

Authenticated crawling, passive reconnaissance and secret validation — for stealthy auditing without an active payload load.

NTLMv2 NEW

The bundled NtlmMessages implements NTLMv2 Type-1 / Type-3 on top of its own MD4 + HMAC-MD5 — no external JCE providers. Enabled through the "NTLM credentials" dialog in Auth Crawl.

CSRF auto-extract NEW

CsrfTokenExtractor reads the token from:

  • <meta name="csrf-token"> (Rails, Laravel, Spring).
  • <input type="hidden"> with typical names: _token, __RequestVerificationToken, authenticity_token, csrfmiddlewaretoken.

The value is masked in the report (prefix/suffix visible, middle replaced with asterisks).

Cookie Flags Auditor

CookieFlagsAuditor parses Set-Cookie and checks:

  • Secure on HTTPS.
  • HttpOnly for session/auth/jwt/token cookies → severity is raised.
  • SameSite (Strict / Lax / None+Secure).

Integrated into PassiveReconService.

Passive Recon Mode

The PassiveReconService collects data without any active payload — suitable for reconnaissance that does not trigger WAF/IDS alerts.

What is collected

  • HTML <title>, security headers, robots.txt, sitemap.xml.
  • Favicon MD5 + lookup against FaviconFingerprintDatabase (Jenkins, GitLab, Confluence, JIRA, Grafana and others).
  • NEW All external origins from the CSP header (connect-src, script-src, img-src).
  • NEW <meta name="generator"> — CMS / framework detection with version.
  • NEW Email addresses from HTML (with a filter against false matches on file extensions).
  • NEW Cross-Origin headers (TAO, CORP, COOP, COEP, ACAO + wildcard / credentials / null-origin).

Secrets Validation

Key-leak validation without any outbound calls. SecretsValidator validates formats:

  • AWS (AKIA…, ASIA…), GitHub PAT (ghp_*, github_pat_*), Stripe, Telegram, Slack (xox*), Google API.
  • NEW NPM token (npm_*), Docker Hub PAT (dckr_pat_*).
  • NEW PEM private-key blocks (BEGIN PRIVATE KEY, BEGIN RSA PRIVATE KEY).
  • NEW GCP Service Account JSON, Google OAuth Client Secret (GOCSPX-).
  • NEW Fuzzy dictionary (secret/password/token/apikey/access_key/auth/bearer) with placeholder-value filter (scanFuzzy()).

Confidence & Risk Score

Every LeakInfo is enriched with:

  • confidence — HIGH / MEDIUM / LOW.
  • priority 1..3 — inferPriority().
  • placeholder — isPlaceholderValue() filters out XXXXXX, your-key-here, etc.
  • risk score = Severity × Exploitability × Exposure.

curl snippets

Anibus Wiki

Guida utente completa per lo scanner di sicurezza Anibus Desktop 2.2.0. Questa wiki documenta i flussi di lavoro, le schermate dell'interfaccia e ogni modulo integrato — dalla ricognizione passiva all'analisi delle SourceMap e al riepilogo AI.

Da dove iniziare Prima volta con Anibus? Leggi Installazione e avvio, poi Scansioni di base. Dopo di che, esplora i moduli secondo necessità — ogni pagina è autonoma.

Cos'è Anibus

Anibus è uno scanner desktop costruito su Java 21 (JavaFX 21.0.5, modulo JPMS it.r2u.anibus) per penetration testing, audit del perimetro e monitoraggio continuo della sicurezza. Tutte le operazioni IO bloccanti girano su virtual thread (JEP 444), le richieste di rete passano attraverso il facade unificato HttpClientFactory con TLS, retry e profili di timeout.

Caratteristiche principali

  • Esecuzione locale senza cloud — tutti i dati restano sulla tua macchina.
  • Locali EN / IT / RU e temi scuro/chiaro.
  • Visual Proxy Chain Builder con drag-and-drop, indicatore ACTIVE CHAIN, rotazione e modalità chain.
  • Virtual thread per probe HTTP massive e detector paralleli.
  • Cache offline CVE/EPSS/KEV con aggiornamento pianificato.

Mappa delle funzionalità

Scansioni di base

TCP/UDP, IPv6, service detection, banner, single-port mode, batch.

Vulnerabilità web

XSS (DOM + Stored + polyglot), SSRF, XXE (OOB), CORS, JWT, GraphQL, SQLi (boolean+time+OOB).

Auth Crawling

5 modalità: Basic / Bearer / OAuth2 client_credentials / Digest RFC 7616 / Form + NTLMv2.

Passive Recon

Title, header, robots, sitemap, favicon MD5, CSP origin, meta-generator, email OSINT, cross-origin policy.

Tech Stack 2.0

40+ signature: server, CMS, framework JS, CDN, analytics, cookie runtime.

CVE Intelligence

Cache NVD offline, probabilità di sfruttamento EPSS, flag CISA KEV, exploit maturity.

Rete e Infra

ASN/BGP, mappa GeoIP, AXFR, HTTP/2/3 ALPN, IPv6, Traceroute TCP/UDP/ICMP, fallback RDAP.

Container e TLS

Esposizione Docker/K8s/etcd, Weak TLS Policy, Auth Surface Audit, Heartbleed con guard anti falso-positivo.

Sottosistema proxy

Visual Chain Builder, rotazione, scheda ACTIVE CHAIN, chain multi-protocollo.

Drift Scheduler

Pianificazioni, profili baseline, severity, regole di soppressione, allerta su nuove porte.

Report

PDF (PrinterJob), HTML stilizzato con filtro JS, cronologia in ~/.anibus/history/, modalità diff.

AI Summary

Riepilogo executive euristico EN/RU sopra JS Analysis senza LLM esterni.

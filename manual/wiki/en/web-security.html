Web vulnerabilities

All web-scanning detectors: XSS, SSRF, XXE, CORS, JWT, GraphQL, SQL Injection, Directory Bruteforce, JS Analysis. In 2.2.0 every analyzer gained new techniques.

XSS Detector

Class XssDetector. Covers reflected, DOM-based and stored XSS.

Reflected (canary-based)

For every query parameter, a canary string such as anibus-xss-7f2a is generated, injected and searched for in the response along with typical contexts.

Context-aware escaping NEW 2.2

The reflection is classified by context via the XssDetector.Context enum:

  • SCRIPT_BLOCK / JS_STRING / URL_ATTRIBUTE — severity CRITICAL.
  • HTML_TEXT / HTML_ATTRIBUTE — severity HIGH.
  • STYLE_BLOCK / HTML_COMMENT — severity MEDIUM.

XssResult gained a field with the recommended escaping for the specific context.

DOM-based sink/source mapping NEW

XssDetector.analyzeDomSinks() scans inline scripts for source→sink pairs: location.hash → innerHTML, document.referrer → eval, etc. The result is shown as a separate table in JS Analysis.

Stored XSS NEW

XssDetector.scanStored(injectUrl, params, verifyUrl): a canary is injected via injectUrl, then a GET against verifyUrl checks for reflection. If found, XssResult.stored=true and the risk is escalated to CRITICAL.

Polyglot payload set NEW

10 techniques: SVG/onload, iframe srcdoc, math/mglyph break-out, body onpageshow, details ontoggle, input autofocus, template literal ${...}, style break-out, jaVasCript: scheme polyglot.

PoC generation

For each result, XssResult.pocCurl() builds a ready-to-run curl snippet with payload and headers, accessible via right-click → Copy PoC.

SSRF Detector

  • URL parameter probing for SSRF + cloud metadata checks (AWS 169.254.169.254, GCP, Azure IMDS).
  • NEW Support for file://, dict://, gopher://, ftp:// schemes.
  • NEW IPv6 / IPv4-mapped bypass (::ffff:169.254.169.254), octal/hex/decimal IP formats, short form (127.1), nip.io DNS rebinding.

XXE Detector

  • 5 baseline payloads + signature-based response detection.
  • NEW OOB XXE via the built-in LoopbackCallbackServer on 127.0.0.1:random — no external server required.
  • NEW scanWithBaseline() — blind XXE/SSRF via response-length diffing.
  • NEW Error-based payload (non-existent path / closed port) with indicators such as Connection refused, failed to open stream, DOCTYPE is disallowed.

CORS Misconfiguration Checker

  • Probes Access-Control-Allow-Origin + credentials combinations.
  • NEW Detects credentials + * (a spec violation).
  • NEW Per-endpoint sweep — check(baseUrl, endpoints).
  • NEW Null-origin probe (Origin: null) and pre-flight headers.

JWT Analyzer

  • Decoding, alg:none, expired tokens, weak HMAC secrets.
  • NEW JWK/JWKS validation (analyzeJwks), kid injection, alg confusion.
  • NEW Kid path traversal (kid: "../../etc/passwd") + SQLi in kid.
  • NEW Insecure token storage — scans JS bundles for localStorage keys.
  • NEW compareTokenPair(access, refresh) — TTL diff advisories.
  • NEW cloneWithClaim(token, claim, value) — tampers sub/role for probing.

GraphQL Introspection

  • 10 paths, __schema, extraction of types / queries / mutations.
  • NEW Batch query abuse — an array of queries inside a single HTTP call.
  • NEW Auto-generates minimal queries/mutations from the schema.
  • NEW Depth-limit probe (depth 12) → flag depthLimitMissing.

SQL Injection Analyzer

  • Loads payload files + CMS profiles.
  • NEW Boolean-based blind via response length and status code diffing.
  • NEW 8 explicit time-based payloads (SLEEP/WAITFOR/pg_sleep/BENCHMARK).
  • NEW OOB payload generator buildOobPayloads(callbackUrl) — MSSQL/Oracle/PostgreSQL/MySQL outbound primitives via LoopbackCallbackServer.
  • SQL-to-DB Extraction: context menu → SqlMetadataExtractor (UNION-based version/columns/tables, ORDER BY probe).

Directory Bruteforce

  • 60-entry default wordlist, HEAD requests, grouping by status.
  • NEW Custom wordlists / extensions + recursion depth — scan(url, words, exts, depth, progress).
  • NEW IIS short-name enumeration (probeIisShortNames()).
  • NEW Backup-file detection (.bak, .old, .orig, ~, .swp).
  • NEW Auto extensions driven by Content-Type/Server (PHP → .php/.phtml, IIS → .aspx, Tomcat → .jsp).
  • NEW Renders HTTP headers (Content-Type, X-Powered-By, Server).

Subdomain Enumeration & Takeover

  • 30+ subdomains checked for dangling DNS, HTTP fingerprinting.
  • NEW CNAME chain recursion via JNDI DNS (resolveCnameChain).
  • NEW +24 fingerprints: Vercel, Render, Fly.io, Pantheon, Strikingly, Tumblr, Campaign Monitor, WordPress, Ngrok, Help Scout, Wishpond, Readme.io, AWS EB, Smartling, Acquia, LeadPages, Railway.
  • NEW DNS wildcard baseline — a random subdomain; on match, a single *.domain advisory is emitted instead of false positives.

API Security Mode

  • Auto-detects OpenAPI/Swagger and tests every endpoint.
  • NEW Support for GraphQL / gRPC / OpenRPC schemas (unified report).
  • NEW Diff of authenticated vs anonymous responses.
  • NEW Rate-limit probe — a burst of 20 requests, expecting 429.
  • NEW Auto parsing of HAR / Postman v2.x via HarPostmanParser.
  • NEW Enum fuzzing of query parameters (role/status/sort/order/filter/debug).
  • NEW BOLA/IDOR probe — runBolaProbe() compares {id}=1 against {id}=2.

JavaScript Security Analyzer

A general-purpose JS bundle analyzer: source parsing, secret discovery, DB schemas, endpoints. Each finding is a LeakInfo with the fields:

  • priority — 1..3, see inferPriority().
  • confidence — HIGH / MEDIUM / LOW.
  • placeholder — flag indicating the value looks like a demo placeholder.
  • risk score — Severity × Exploitability × Exposure.

JS Endpoint Reachability NEW

Endpoints discovered in JS are probed for liveness, status and method. The result is a Reachable / 401 / 403 / 404 / 5xx table with a curl snippet for each live URL.

AI Summary NEW

AiSummaryGenerator produces an EN/RU executive summary: severity buckets, top-5 categories, top-3 risk-scored findings, type-aware recommendations. Fully offline, no LLM API.

OOB infrastructure

LoopbackCallbackServer is a built-in HTTP listener on 127.0.0.1:random. It is used by SSRF/XXE/SQLi/Blind XSS payloads to confirm an out-of-band hit without any external internet infrastructure.

Caution All web-vulnerability detectors send active requests. Use only against authorized targets. For passive auditing see Passive Recon.

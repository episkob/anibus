Rete e infrastruttura

Arricchimento ASN/BGP, mappa GeoIP, AXFR, ALPN HTTP/2 e HTTP/3, IPv6, traceroute in tre modalità, WHOIS con fallback RDAP.

ASN / BGP Enrichment NEW

Record BgpInfo + bulk whois Team Cymru:

  • ASN, owner, country, prefix, route age.
  • ASN adiacenti.
  • Query in batch tramite whois TCP (senza API HTTP).

Usato nella Topology Map (clustering degli hop per /24 + ASN) e in JS Analysis per classificare provider CDN/cloud.

ASN Lookup standalone

AsnLookupService — determinazione dell'AS da IP tramite parsing whois/IANA senza API esterne. Menu Discovery → ASN Lookup.

GeoIP Map View NEW

GeoIpService + bar-chart ASCII per paese. Mostra:

US ████████████████████  42
DE ███████              14
NL ████                  9
RU ██                    4
CN █                     2

Sorgente GeoIP locale (senza chiamate a MaxMind in runtime).

Network Topology Map

Una scheda dedicata visualizza il traceroute come grafo hop→hop:

  • NEW Clustering degli hop per prefisso /24 + ASN.
  • NEW Zoom-to-fit, zoom manuale con la rotella, drag-pan con il mouse.
  • Evidenziazione dei punti di failure (alto ICMP loss).

Traceroute (3 modalità)

Enum TracerouteService.Mode:

ModalitàQuando usarla
ICMPClassico traceroute Linux, può essere filtrato dal firewall.
UDPPacchetto UDP su porta alta; aggira parte dei filtri ICMP.
TCPSYN su una porta specifica (80/443) — passa attraverso la maggior parte dei NAT/SPI.

Metriche: hop, ASN, RTT min/avg/max, packet loss %, owner.

WHOIS Lookup + RDAP

WhoisService:

  • Query a due passi: root IANA → server autoritativo.
  • NEW Fallback RDAP per i registry moderni (.io, .dev, .app).
  • NEW Normalizzazione dei campi registrar / abuse contact tra formati diversi.

DNS Zone Transfer (AXFR)

Raw TCP/53 AXFR senza librerie esterne. Vengono parsati i record A / AAAA / NS / MX / CNAME e visualizzati come albero. Se AXFR è proibito — fallback graceful senza rumore in console.

Detector HTTP/2 + HTTP/3

  • HTTP/2 — negoziazione ALPN (h2) su 443/TLS.
  • HTTP/3 — header Alt-Svc: h3=":443" + probe UDP/443.

WebSocket Detector

Probe HTTP Upgrade: websocket su 17 path tipici (/ws, /socket.io/, /cable, /api/ws, ...). In caso di successo viene registrato il protocollo (Sec-WebSocket-Protocol).

IPv6

HostResolver supporta IPv6:

  • Rimozione delle parentesi quadre: [::1] → ::1.
  • Skip IDN su IPv6 raw.
  • Multi-resolution: A + AAAA in contemporanea.
  • Zone-ID per link-local: fe80::1%eth0.

SSL/TLS Deep Audit

SslTlsAuditor produce AuditResult:

  • Protocollo, cipher suite, catena di certificati, lista SAN, scadenza.
  • NEW URL OCSP, header HSTS, lista ALPN.
  • NEW Chain trust tramite il TrustManager JVM di default.

Il risultato confluisce in Weak TLS Policy Alerts.

Port Banner Timeline NEW

BannerTimelineService conserva uno store TSV in ~/.anibus/banner-timeline/. Per ogni porta viene tenuta una cronologia (timestamp + banner). Il diff tra due punti mostra l'aggiornamento del servizio (per esempio OpenSSH 9.0p1 → 9.6p1).

Reverse DNS Expander

ReverseDnsExpander — per un blocco CIDR espande i record PTR tramite virtual thread. Utile per l'inventario di un range aziendale.

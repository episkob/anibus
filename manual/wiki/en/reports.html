Export & history

Saving, exporting and analyzing results: PDF, HTML, JSON, history, diff and AI summary.

Export formats

FormatPurposeCommand
PDFPrintable report for management / clientExport → PDF (JavaFX PrinterJob)
HTMLInteractive report with a filterExport → HTML
JSONMachine-readable, for SIEM/CI integrationExport → JSON
TXTFlat console logExport → TXT or Ctrl+S

HTML report

Styled HTML with a result table and an embedded JS filter (text search, severity filter, section collapsing). No server required — opens directly in a browser.

PDF

JavaFX PrinterJob renders the DOM report page by page. Header with target, date and Anibus version; CVE table; JS Analysis section; appendix with PoC curl snippets.

Scan history

ScanHistoryService auto-saves every completed scan to ~/.anibus/history/ with a name like 2026-05-15T12-34-01_example.com.scan.json.

Viewing

Menu Discovery → Scan History:

  • Scan list with filtering by date/target.
  • Double-click to open.
  • Right-click → Compare with… launches the diff.
  • Right-click → Re-run repeats the scan with the same parameters.

Diff mode

ScanDiffService compares two JSON history snapshots:

  • NEW — new open ports, new CVEs, new leaks.
  • CHANGED — version/banner changed.
  • GONE — a port closed or a vulnerability disappeared.

The diffModeButton on the main screen opens a wizard with two scan dropdowns.

Statistic Dashboard

A tab with distribution charts:

  • Open ports by top services.
  • Vulnerabilities by severity (CRITICAL/HIGH/MEDIUM/LOW).
  • Top ASNs/countries (via GeoIP).
  • Drift-scan trends from ScanHistoryService.

AI Summary NEW

AiSummaryGenerator produces an executive summary for JS Analysis with no external LLM. The algorithm is heuristic:

  • Severity buckets (Critical / High / Medium / Low / Informational).
  • Top-5 finding categories (Secrets / Endpoints / Configs / Schemas / Cookies / Generators / Other).
  • Top-3 risk-scored findings (Severity × Exploitability × Exposure).
  • Type-aware recommendations: AWS keys — rotation + CloudTrail audit; GitHub PAT — revoke and review commit history; and so on.

Emitted in two languages at once (EN / RU). Available in JS Analysis → Summary tab.

SourceMap Exploit Context NEW

SourceMapExploitContextAnalyzer enriches every LeakInfo extracted from a source map with an annotation:

  • category — attack class (SSRF / Auth-bypass / Privilege-escalation / Data-exfil / RCE).
  • narrative — short context description (where the key came from, how it's used).
  • recommendation — a concrete action (rotation / removal / vault).
  • ref — a link to a CVE / OWASP category.

Sorting and filtering

  • JS Analysis sorts findings by priority (descending) within each severity tier.
  • Ctrl+F — inline Scan Results filter.
  • The HTML report has its own independent JS filter in the browser.

System notifications

NotificationService uses java.awt.SystemTray to show tray notifications:

  • "Scan finished" — after completion.
  • "CRITICAL detected" — on the first CRITICAL finding.
  • "Scheduler drift" — changes in the drift baseline.

Batch export

From BatchScanService the report is exported as a single archive: batch-YYYYMMDD.zip contains per-target JSON + a consolidated HTML.

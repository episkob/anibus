Экспорт и история

Сохранение, экспорт и анализ результатов: PDF, HTML, JSON, история, diff и AI-сводка.

Форматы экспорта

ФорматНазначениеКоманда
PDFПечатный отчёт для менеджмента / клиентаExport → PDF (JavaFX PrinterJob)
HTMLИнтерактивный отчёт с фильтромExport → HTML
JSONМашиночитаемый, для интеграции в SIEM/CIExport → JSON
TXTПлоский лог консолиExport → TXT или Ctrl+S

HTML-отчёт

Styled HTML с таблицей результатов и встроенным JS-фильтром (поиск по тексту, фильтр по severity, сворачивание секций). Не требует сервера — открывается напрямую в браузере.

PDF

JavaFX PrinterJob рендерит DOM-отчёт постранично. Шапка с целью, датой, версией Anibus; таблица CVE; раздел JS Analysis; appendix с PoC curl-сниппетами.

История сканов

ScanHistoryService автосохраняет каждый завершённый скан в ~/.anibus/history/ с именем вида 2026-05-15T12-34-01_example.com.scan.json.

Просмотр

Меню Discovery → Scan History:

  • Список сканов с фильтром по дате/цели.
  • Двойной клик — открыть.
  • ПКМ → Compare with… запускает diff.
  • ПКМ → Re-run повторяет скан с теми же параметрами.

Diff-режим

ScanDiffService сравнивает два json-снимка истории:

  • NEW — новые открытые порты, новые CVE, новые leaks.
  • CHANGED — версия/баннер изменились.
  • GONE — закрылся порт или исчезла уязвимость.

Кнопка diffModeButton на главной открывает мастер с двумя выпадающими списками сканов.

Statistic Dashboard

Вкладка с графиками распределения:

  • Открытые порты по топ-сервисам.
  • Уязвимости по severity (CRITICAL/HIGH/MEDIUM/LOW).
  • Топ ASN/стран (через GeoIP).
  • Динамика drift-сканов из ScanHistoryService.

AI Summary NEW

AiSummaryGenerator формирует executive-сводку для JS Analysis без внешних LLM. Алгоритм эвристический:

  • Severity buckets (Critical / High / Medium / Low / Informational).
  • Top-5 категорий находок (Secrets / Endpoints / Configs / Schemas / Cookies / Generators / Other).
  • Top-3 risk-scored находки (Severity × Exploitability × Exposure).
  • Type-aware рекомендации: для AWS-ключей — ротация + audit CloudTrail; для GitHub PAT — revoke и проверка истории коммитов и т.д.

Выходит в двух языках одновременно (EN / RU). Доступно в JS Analysis → Summary вкладка.

SourceMap Exploit Context NEW

SourceMapExploitContextAnalyzer расширяет каждый LeakInfo, извлечённый из source-map, аннотацией:

  • category — класс атаки (SSRF / Auth-bypass / Privilege-escalation / Data-exfil / RCE).
  • narrative — короткое описание контекста (откуда взялся ключ, как используется).
  • recommendation — конкретное действие (ротация / удаление / vault).
  • ref — ссылка на CVE / OWASP-категорию.

Сортировка и фильтр

  • JS Analysis сортирует находки по priority (убывание) внутри каждого тира severity.
  • Ctrl+F — inline-фильтр Scan Results.
  • HTML-отчёт имеет независимый JS-фильтр в браузере.

Системные уведомления

NotificationService через java.awt.SystemTray показывает tray-уведомления:

  • «Scan finished» — после завершения.
  • «CRITICAL detected» — при первой CRITICAL-находке.
  • «Scheduler drift» — изменения в drift-baseline.

Batch-экспорт

Из BatchScanService отчёт выгружается одним архивом: batch-YYYYMMDD.zip содержит per-target JSON + сводный HTML.

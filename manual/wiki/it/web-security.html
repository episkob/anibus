Vulnerabilità web

Tutti i detector per le scansioni web: XSS, SSRF, XXE, CORS, JWT, GraphQL, SQL Injection, Directory Bruteforce, JS Analysis. In 2.2.0 ogni analyzer è stato esteso con nuove tecniche.

XSS Detector

Classe XssDetector. Copre XSS reflected, DOM-based e stored.

Reflected (canary-based)

Per ogni parametro di query viene generata una stringa canary del tipo anibus-xss-7f2a, iniettata e cercata nella risposta insieme ai contesti tipici.

Escaping context-aware NEW 2.2

La riflessione viene classificata per contesto tramite l'enum XssDetector.Context:

  • SCRIPT_BLOCK / JS_STRING / URL_ATTRIBUTE — severity CRITICAL.
  • HTML_TEXT / HTML_ATTRIBUTE — severity HIGH.
  • STYLE_BLOCK / HTML_COMMENT — severity MEDIUM.

In XssResult è stato aggiunto un campo con la raccomandazione di escaping specifica per il contesto.

Mappatura DOM-based sink/source NEW

XssDetector.analyzeDomSinks() esamina gli script inline alla ricerca di coppie source→sink: location.hash → innerHTML, document.referrer → eval ecc. Il risultato è mostrato in una tabella separata in JS Analysis.

Stored XSS NEW

XssDetector.scanStored(injectUrl, params, verifyUrl): viene iniettato un canary tramite injectUrl, poi viene eseguita una GET su verifyUrl e si verifica la riflessione. Se rilevata — XssResult.stored=true, il rischio sale a CRITICAL.

Set di payload polyglot NEW

10 tecniche: SVG/onload, iframe srcdoc, math/mglyph break-out, body onpageshow, details ontoggle, input autofocus, template literal ${...}, style break-out, polyglot dello schema jaVasCript:.

Generazione PoC

Per ogni risultato — XssResult.pocCurl() costruisce uno snippet curl pronto con payload e header, disponibile tramite tasto destro → Copy PoC.

SSRF Detector

  • Parametri URL per SSRF + check dei metadata cloud (AWS 169.254.169.254, GCP, Azure IMDS).
  • NEW Supporto per gli schemi file://, dict://, gopher://, ftp://.
  • NEW Bypass IPv6/IPv4-mapped (::ffff:169.254.169.254), formati IP ottali/hex/decimali, short-form (127.1), DNS rebinding tramite nip.io.

XXE Detector

  • 5 payload di base + rilevamento tramite signature nella risposta.
  • NEW OOB XXE tramite LoopbackCallbackServer integrato su 127.0.0.1:random — non serve un server esterno.
  • NEW scanWithBaseline() — blind XXE/SSRF tramite diff della lunghezza della risposta.
  • NEW Payload error-based (percorso inesistente / porta chiusa) con indicatori Connection refused, failed to open stream, DOCTYPE is disallowed.

CORS Misconfiguration Checker

  • Verifica di Access-Control-Allow-Origin + combinazioni con credentials.
  • NEW Rilevamento di credentials + * (violazione della specifica).
  • NEW Sweep per-endpoint — check(baseUrl, endpoints).
  • NEW Probe di null origin (Origin: null) e header di pre-flight.

JWT Analyzer

  • Decodifica, alg:none, expired, segreti HMAC deboli.
  • NEW Check JWK/JWKS (analyzeJwks), kid injection, alg-confusion.
  • NEW Kid path traversal (kid: "../../etc/passwd") + SQLi nel kid.
  • NEW Storage non sicuro del token — ricerca di chiavi localStorage nei bundle JS.
  • NEW compareTokenPair(access, refresh) — advisory su diff di TTL.
  • NEW cloneWithClaim(token, claim, value) — tamper di sub/role per il probing.

GraphQL Introspection

  • 10 path, __schema, estrazione di tipi/query/mutation.
  • NEW Batch query abuse — array di query in un'unica chiamata HTTP.
  • NEW Auto-generazione di query/mutation minime a partire dallo schema.
  • NEW Probe di depth-limit (profondità 12) → flag depthLimitMissing.

SQL Injection Analyzer

  • Caricamento di file di payload + profili CMS.
  • NEW Boolean-based blind tramite diff sulla lunghezza della risposta e sullo status code.
  • NEW 8 payload time-based espliciti (SLEEP/WAITFOR/pg_sleep/BENCHMARK).
  • NEW OOB payload generator buildOobPayloads(callbackUrl) — primitive outbound MSSQL/Oracle/PostgreSQL/MySQL tramite LoopbackCallbackServer.
  • SQL-to-DB Extraction: menu contestuale → SqlMetadataExtractor (UNION-based version/columns/tables, probe ORDER BY).

Directory Bruteforce

  • Wordlist di default da 60 voci, richieste HEAD, raggruppamento per status.
  • NEW Wordlist/estensioni personalizzate + recursion depth — scan(url, words, exts, depth, progress).
  • NEW Enumerazione di IIS short-name (probeIisShortNames()).
  • NEW Rilevamento di file di backup (.bak, .old, .orig, ~, .swp).
  • NEW Estensioni automatiche in base a Content-Type/Server (PHP → .php/.phtml, IIS → .aspx, Tomcat → .jsp).
  • NEW Visualizzazione degli header HTTP (Content-Type, X-Powered-By, Server).

Subdomain Enumeration & Takeover

  • 30+ sottodomini su dangling DNS, fingerprint HTTP.
  • NEW Ricorsione sulla catena CNAME tramite JNDI DNS (resolveCnameChain).
  • NEW +24 fingerprint: Vercel, Render, Fly.io, Pantheon, Strikingly, Tumblr, Campaign Monitor, WordPress, Ngrok, Help Scout, Wishpond, Readme.io, AWS EB, Smartling, Acquia, LeadPages, Railway.
  • NEW Baseline DNS wildcard — sottodominio casuale; in caso di match viene emesso un singolo avviso *.domain invece di falsi positivi.

API Security Mode

  • Auto-detect di OpenAPI/Swagger, test di tutti gli endpoint.
  • NEW Supporto agli schemi GraphQL/gRPC/OpenRPC (report unificato).
  • NEW Diff fra risposte autenticate e anonime.
  • NEW Probe di rate-limit — serie di 20 richieste, attesa di 429.
  • NEW Parsing automatico di HAR / Postman v2.x tramite HarPostmanParser.
  • NEW Enum-fuzzing dei parametri di query (role/status/sort/order/filter/debug).
  • NEW Probe BOLA/IDOR — runBolaProbe() confronta {id}=1 vs {id}=2.

JavaScript Security Analyzer

Analyzer universale di bundle JS: parsing dei sorgenti, ricerca di segreti, schemi DB, endpoint. Ogni scoperta è un LeakInfo con i campi:

  • priority — 1..3, vedi inferPriority().
  • confidence — HIGH / MEDIUM / LOW.
  • placeholder — flag che indica se il valore sembra un placeholder demo.
  • risk score — Severity × Exploitability × Exposure.

JS Endpoint Reachability NEW

Gli endpoint trovati nel JS vengono verificati per liveness, status e metodo. Il risultato è una tabella Reachable / 401 / 403 / 404 / 5xx con uno snippet curl per ogni URL attivo.

AI Summary NEW

AiSummaryGenerator produce un riepilogo executive EN/RU: severity buckets, top-5 categorie, top-3 scoperte per risk score, raccomandazioni type-aware. Completamente offline, senza API LLM.

Infrastruttura OOB

LoopbackCallbackServer — listener HTTP integrato su 127.0.0.1:random. Usato nei payload SSRF/XXE/SQLi/Blind XSS per confermare l'out-of-band senza infrastruttura Internet esterna.

Attenzione Tutti i detector di vulnerabilità web eseguono richieste attive. Usali solo su target autorizzati. Per audit passivo — Passive Recon.

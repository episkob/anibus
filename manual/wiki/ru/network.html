Сеть и инфраструктура

ASN/BGP-обогащение, GeoIP-карта, AXFR, HTTP/2 и HTTP/3 ALPN, IPv6, traceroute в трёх режимах, WHOIS с RDAP-fallback.

ASN / BGP Enrichment NEW

BgpInfo record + Team Cymru whois bulk query:

  • ASN, owner, country, prefix, route age.
  • Соседние ASN.
  • Запрос пачкой через TCP-whois (без HTTP-API).

Используется в Topology Map (кластеризация hop по /24 + ASN) и в JS Analysis для классификации CDN/cloud-провайдеров.

ASN Lookup standalone

AsnLookupService — определение AS по IP через парсинг whois/IANA без внешних API. Меню Discovery → ASN Lookup.

GeoIP Map View NEW

GeoIpService + ASCII bar-chart по странам. Выводит:

US ████████████████████  42
DE ███████              14
NL ████                  9
RU ██                    4
CN █                     2

Локальный GeoIP-источник (без обращения к MaxMind в runtime).

Network Topology Map

Отдельная вкладка визуализирует traceroute как граф hop→hop:

  • NEW Кластеризация hop по /24-префиксу + ASN.
  • NEW Zoom-to-fit, ручной zoom колесом, drag-pan мышью.
  • Подсветка точек отказа (большой ICMP-loss).

Traceroute (3 режима)

TracerouteService.Mode enum:

РежимКогда применять
ICMPКлассический Linux traceroute, может фильтроваться firewall-ом.
UDPUDP-пакет на высокий порт; обходит часть ICMP-фильтров.
TCPSYN на конкретный порт (80/443) — проходит через большинство NAT/SPI.

Метрики: hop, ASN, RTT min/avg/max, packet-loss %, owner.

WHOIS Lookup + RDAP

WhoisService:

  • Двухэтапный запрос: IANA root → авторитативный сервер.
  • NEW RDAP fallback для современных регистратур (.io, .dev, .app).
  • NEW Нормализация полей registrar / abuse contact между разными форматами.

DNS Zone Transfer (AXFR)

Raw TCP/53 AXFR без сторонних библиотек. Парсятся записи A / AAAA / NS / MX / CNAME, выводится в виде дерева. Если AXFR запрещён — graceful fallback без шума в консоль.

HTTP/2 + HTTP/3 детектор

  • HTTP/2 — ALPN negotiation (h2) на 443/TLS.
  • HTTP/3 — Alt-Svc: h3=":443" header + UDP/443 проба.

WebSocket Detector

HTTP Upgrade: websocket probe по 17 типичным путям (/ws, /socket.io/, /cable, /api/ws, ...). При успехе фиксируется протокол (Sec-WebSocket-Protocol).

IPv6

HostResolver поддерживает IPv6:

  • Strip квадратных скобок: [::1] → ::1.
  • Skip IDN на raw-IPv6.
  • Multi-resolution: A + AAAA одновременно.
  • Zone-ID для link-local: fe80::1%eth0.

SSL/TLS Deep Audit

SslTlsAuditor формирует AuditResult:

  • Протокол, cipher suite, цепочка сертификатов, SAN-список, expiry.
  • NEW OCSP URL, HSTS header, ALPN-список.
  • NEW Chain trust через default JVM TrustManager.

Результат подаётся в Weak TLS Policy Alerts.

Port Banner Timeline NEW

BannerTimelineService хранит TSV-store в ~/.anibus/banner-timeline/. На каждый порт ведётся история (timestamp + banner). Diff между двумя точками показывает обновление сервиса (например, OpenSSH 9.0p1 → 9.6p1).

Reverse DNS Expander

ReverseDnsExpander — для CIDR-блока расширяет PTR-записи через virtual threads. Полезно для inventory корпоративного диапазона.

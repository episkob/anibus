Установка и запуск

Минимальный путь от чистой системы до первого скана в Anibus 2.2.0.

Системные требования

КомпонентМинимумКомментарий
ОСLinux x64 / macOS / Windows 10+Тестируется на Linux (Fedora/Ubuntu). На Wayland — без особенностей.
JDKJava 21 (LTS)Требуется поддержка virtual threads (JEP 444), preview-флаги не нужны.
JavaFX21.0.5Подтягивается Maven-зависимостью, отдельная установка не требуется.
Maven3.9+В проекте есть ./mvnw, можно использовать его.
RAM1 GBДля batch-сканов 100+ целей рекомендуется 2 GB и выше.
ПраваОбычный пользовательДля UDP-скана некоторых служб может понадобиться root/CAP_NET_RAW.

Сборка из исходников

git clone <repo> anibus-desktop
cd anibus-desktop
./mvnw -B -DskipTests package
./mvnw -B -Pjavafx javafx:run

Артефакты после сборки лежат в target/. Тесты (162 шт., 50+ классов) запускаются командой:

./mvnw -B test

Запуск конкретного теста:

./mvnw -B test -Dtest=SQLInjectionAnalyzerTest

Первый запуск

  1. Окно открывается в тёмной теме (Bootstrap 5 Dark, кастомный CSS).
  2. В заголовке окна — версия Anibus Desktop 2.2.0.
  3. Левая часть — поле Target и группа кнопок сканирования.
  4. Центр — консоль Scan Results с realtime-таймстампом и фильтром (Ctrl+F).
  5. Верхнее меню — конфигурация, тема, словари, прокси, scheduler, экспорт.
Совет На первом запуске откройте Config → Тема и выберите Тёмная или Светлая. Светлая тема — это override-CSS anibus-style-light.css.

Структура каталогов пользователя

ПутьНазначение

~/.anibus/cve-cache/Офлайн-кэш CVE/EPSS/KEV (см. CVE Offline DB).

~/.anibus/banner-timeline/TSV-store для Port Banner Timeline.

Обзор интерфейса

Главное окно

  • Target — IPv4/IPv6/hostname/URL; квадратные скобки в IPv6 раскрываются автоматически.
  • Scan Results — консоль с группами CRITICAL/HIGH/MEDIUM/LOW. Контекстное меню → история, diff, SQL-extraction.
  • Кнопки слева — Scan, UDP, Subdomain, Source Map, ParamMiner, Diff Mode, Scheduler Start/Stop и т.д. Подробно — в Базовых сканах.
  • Status bar — индикаторы активных словарей, прокси-чейна, scheduler-состояния.

Меню

  • Config — тема, язык, словари, профили таймаутов.
  • Discovery — Auth Crawling, Passive Recon, GraphQL/JWT/CORS-диалоги, batch-импорт.
  • Proxy — Build Chain, ACTIVE CHAIN, ротация.
  • Scheduler — расписания, drift-baseline.
  • Export — PDF, HTML, JSON, TXT.

Локализация

Все строки UI собраны в три bundle: Messages_en, Messages_it, Messages_ru. Синхронность ключей проверяется JUnit-тестом ResourceBundleValidationTest. Локаль определяется системной, явно переключается в Config → Язык.

Что дальше

  • Запустите первый скан по любой публично разрешённой цели (scanme.nmap.org или собственный лаб).
  • Изучите прокси-цепочки, если сканируете через корпоративный шлюз.
  • Включите офлайн-кэш CVE, если работаете в air-gapped окружении.
